# 원소 데이터 출처와 검증

- 기호·영문 이름·주기·족·계열: PyPI 패키지 `mendeleev` 1.3.0에 포함된 `elements.db`
  (`tools/build_elements.py`가 이 파일을 읽어 `elements.json`을 생성).
- 한국어 이름: 대한화학회 원소 이름 표기(2014 개정). 교과서·일상에서 쓰는 이전 이름(나트륨, 칼륨, 브롬 등)은
  `aliasesKo`에 따로 저장하고, 화면에는 `소듐(나트륨)`처럼 공식 이름 뒤 괄호로 표시합니다.
- 표시 위치 규칙(우리 결정): 란타넘족(57–71)과 악티늄족(89–103) 15개씩을 본표 아래 두 줄(행 9, 10, 열 3–17)에
  두고 `group = null`(족 해당 없음)로 둡니다. 3족 자리(6·7주기)는 비워 둡니다. 3족에 La/Ac를 둘지 Lu/Lr을 둘지는
  학계에서 논의 중이므로, 학교 교과서에서 흔한 15개 묶음 표기를 따랐습니다. `mendeleev`는 La·Ac를 3족, Lu·Lr을
  전이금속으로 분류하므로 이 30개 원소의 족·계열은 원본과 다르게 의도적으로 덮어썼습니다.

## 검증

`python3 tools/validate_elements.py`가 확인하는 것:
- 원자번호 1–118 누락·중복 없음, 기호·한국어 이름·영문 이름 중복 없음
- 표시 칸 중복 없음, 비 f-블록 원소의 표시 칸 = (주기, 족)
- 각 주기의 첫 원소는 1족, 마지막 원소는 18족
- 학교 수준 기준값 10개(H, He, C, Na, Cl, Ca, Fe, Kr, Au, Og) 일치
