# 원소잠금 개인정보처리방침 (초안)

시행일: 출시일에 맞춰 기입

원소잠금(이하 "앱")은 개인정보를 수집하지 않습니다.

1. **수집하는 정보: 없음.** 회원가입, 로그인, 광고, 분석 도구, 서버가 없습니다.
2. **기기 안에만 저장하는 정보**: 학습 범위·설정, 문제 풀이 기록(원소별 정답 여부와 날짜), 제한할 앱 선택 정보, 동작 진단 기록.
   이 정보는 기기 밖으로 전송되지 않으며, 앱을 삭제하면 함께 삭제됩니다.
3. **iOS 스크린 타임 권한**: 사용자가 고른 앱에 차단 화면을 적용하는 데에만 씁니다. 선택한 앱은 Apple이 제공하는 불투명한 토큰으로만
   다뤄지며, 앱은 앱 이름이나 사용 기록을 읽거나 전송하지 않습니다.
4. **Android 접근성 서비스**: 지금 열린 앱의 패키지 이름만 확인해, 사용자가 고른 앱이면 학습 화면을 띄웁니다. 화면 내용, 입력한 글자,
   메시지, 비밀번호를 읽지 않고 저장하지 않으며, 어떤 정보도 전송·공유하지 않습니다. Android 앱에는 인터넷 권한이 없습니다.
5. **제3자 제공·국외 이전**: 없습니다.
6. **아동**: 회원가입과 정보 수집이 없으므로 별도의 아동 개인정보 처리가 없습니다.
7. **문의**: (개발자 이메일 기입)
