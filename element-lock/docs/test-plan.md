타입 검사도 일부러 넣은 오류를 잡는 것을 확인했습니다.

**실행하지 못한 것**: Swift XCTest(`swift test`, macOS 필요), Android `:app` Gradle 빌드·lint·계측 테스트(Android SDK 필요),
iOS 빌드(Xcode 필요). 이들은 통과했다고 볼 수 없습니다.
