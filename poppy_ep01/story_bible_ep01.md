# 뽀삐의 다음 장면: 설정 파일 (1화 기준)

## 캐릭터: 뽀삐 (실제 반려견 사진 기준)
| 항목 | 고정값 |
|---|---|
| 견종 느낌 | 파피용, 소형견, **항상 네 발로 이동** (사람 손·사람 몸 금지) |
| 귀 | 커다란 검은 나비 모양 귀, 가장자리에 긴 장식털 |
| 얼굴 | 이마에서 코까지 흰 무늬(블레이즈), 눈 주위는 검정, 볼과 눈 위에 옅은 갈색 털, 둥근 검은 눈, 작은 검은 코 |
| 몸 | 흰 몸, 풍성한 털 |
| 꼬리 | 등 위로 말린 풍성한 흰 꼬리 (끝에 검은 털) |
| 소품 | **연분홍 하네스** + 분홍빛 리드줄 (모든 장면 필수) |
| 연기 원칙 | 립싱크 대신 표정·귀·시선으로 연기. 1화 감정선: 호기심 → 의심 → 당황 |
| 목소리 | 뽀삐 대사·내레이션·상자 속 목소리가 **같은 목소리**. 상자 속은 먹먹한 필터만 적용 |

## 1화에서 확정된 사실 (다음 편에서 바꾸면 안 되는 것)
1. 장소: 해 질 무렵, 꽃이 핀 조용한 공원 산책길. 주변에 사람이 없음.
2. 길 위에 작은 갈색 골판지 택배 상자가 있음. 크기는 뽀삐 머리 정도, 흰 이름표에 **"받는 이: 뽀삐"**라고 적혀 있음.
3. 뽀삐는 아무것도 주문한 기억이 없음 ("내가… 뭘 시켰나?").
4. 상자 안에서 '톡, 톡' 두 번 소리가 남. 뽀삐가 앞발로 모서리를 건드리자 상자가 아주 조금 움직임.
5. 상자 속 목소리는 뽀삐와 같은 목소리. 상자 속에서 한 말은 다음 세 마디뿐임.
   - "열지 마."
   - "나야. 뽀삐."
   - "내가 나가면… 네가 들어와야 해."
6. 뽀삐가 한 발 물러서자 상자 틈에서 희미하고 따뜻한 빛이 새어 나옴.
7. **상자는 열리지 않았음. 안에 무엇이 있는지는 아무도 보지 못했음.**
8. 마지막 질문: "그럼 지금 밖에 있는 나는 누구지?" 뽀삐는 상자 옆에서 망설이는 상태로 끝남.

## 아직 정하지 않은 것 (댓글을 받은 뒤 결정)
- 상자 속 존재의 정체 / 진짜 뽀삐가 누구인지
- 택배를 보낸 사람
- 빛의 의미
- 뽀삐가 다음에 할 행동

## 금지 규칙
- "사실 꿈이었다" 결말 금지
- 잔혹 묘사·갑자기 놀래키는 공포 효과 금지 (호기심과 긴장감으로 끌고 감)
- 실제 댓글이나 투표 결과를 지어내지 않음
