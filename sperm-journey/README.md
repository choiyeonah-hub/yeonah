# 정자의 여행 — 난자를 찾아서

가족이 함께 웃으며 하는 생명 탄생 미니게임입니다. 정자 한 마리를 조종해 산성 방울, 자궁경부의
점액 벽, 백혈구, 나팔관의 역류를 지나 난자까지 헤엄쳐 갑니다. 구간을 지날 때마다 생명 상식이
한 줄씩 뜨고, 도착하면 "내가 태어나던 날" 이야기를 나눠 보라는 가족 질문으로 끝납니다.

## 실행

빌드도, 설치도 필요 없습니다.

- `index.html` 파일을 브라우저로 열면 바로 실행됩니다.
- 로컬 서버로 열고 싶다면: `python3 -m http.server 8000` 후 <http://localhost:8000> 접속.
- 배포: 이 폴더를 그대로 Vercel·Netlify·GitHub Pages에 올리면 됩니다(정적 사이트).

## 조작

- 화면을 위아래로 쓸기(모바일) / 마우스를 위아래로 움직이기 / 방향키 ↑↓ (또는 W·S)
- 스페이스바 또는 화면 터치로 시작·재도전
- 체력은 하트 3개. 부딪히면 하나 줄고 잠시 무적이 됩니다.
- 노란 에너지(⚡)를 먹으면 잠깐 빨라집니다.

## 구간

| 구간 | 무대 | 장애물 |
| --- | --- | --- |
| 1 | 출발 | 산성 방울 |
| 2 | 자궁경부 | 점액 벽의 좁은 틈 |
| 3 | 자궁 | 정자를 쫓아오는 백혈구 |
| 4 | 나팔관 | 통로가 좁아지고 역류가 속도를 늦춤 |

난자에 도착하면 성공. 최고 기록(에너지 개수 → 같은 경우 더 짧은 시간)은 브라우저
`localStorage`에만 저장되며 서버로 전송되지 않습니다.

## 파일 구조

```
index.html      # 화면 뼈대 (캔버스 + 시작/결과 카드 + 구간 안내)
styles.css      # 화면 스타일
js/rules.js     # 상수·구간 데이터·통로 지형·장애물 생성·기록 저장
js/render.js    # 캔버스 그리기 (상태를 바꾸지 않음)
js/main.js      # 게임 루프, 조작, 화면 전환
```

난이도를 바꾸고 싶다면 `js/rules.js` 위쪽 상수부터 만져 보세요.
`BASE_SPEED`(기본 속도), `TOTAL_DISTANCE`(전체 거리), `MAX_HP`(체력), `INVULN_MS`(무적 시간),
그리고 `spawnAt`의 `gap`(장애물 간격)이 체감 난이도를 좌우합니다.
