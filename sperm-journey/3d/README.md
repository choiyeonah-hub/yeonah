# 정자의 여행 3D

2D판과 같은 게임을 three.js와 WebGL로 다시 만든 버전입니다. 통로가 실제 관으로 바뀌어
상하좌우 어디로든 헤엄칠 수 있고, 등장하는 모든 입체 모형은 블렌더가 만듭니다.

## 실행

3D판은 `file://`로 열면 브라우저 보안 정책(모듈·glb 요청 차단)에 막힙니다. 로컬 서버로 여세요.

```bash
cd sperm-journey
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000/3d/
```

배포는 2D판과 같습니다. 폴더를 그대로 정적 호스팅에 올리면 됩니다.

## 조작

마우스나 손가락으로 통로 단면 위를 상하좌우로 움직입니다. 방향키(또는 WASD)도 같습니다.
체력은 하트 3개, 노란 에너지를 먹으면 잠깐 빨라지고 꼬리도 더 빨리 움직입니다.

## 3D 에셋은 어떻게 만들었나

`tools/make_assets.py`가 블렌더 파이썬 API로 모든 모형을 만들고 `assets/*.glb`로 내보냅니다.
바이너리를 손으로 만들어 넣지 않았기 때문에, 모양을 바꾸려면 스크립트의 숫자를 고치고 다시
돌리면 됩니다.

| 에셋 | 내용 |
| --- | --- |
| `sperm.glb` | 머리·중간조각·꼬리. 꼬리에 뼈대 8개와 24프레임짜리 `swim` 애니메이션 |
| `cell.glb` | 백혈구. 구를 울퉁불퉁하게 변형하고 어두운 핵을 넣음 |
| `acid.glb` | 산성 방울. 한쪽이 뾰족한 물방울, 반투명 발광 |
| `energy.glb` | 각진 보석 모양의 에너지 |
| `egg.glb` | 난자. 핵 + 반투명 투명대 + 난구세포 46개 |
| `ring.glb` | 점액 고리. 불리언으로 구멍을 뚫은 판 |
| `models.json` | 위 여섯 개를 base64로 묶은 번들. 게임이 실제로 읽는 파일 |

게임은 `.glb`를 하나씩 읽지 않고 `models.json` 번들 하나만 읽습니다. `.glb` 확장자를 서빙하지
않는 정적 호스팅이 있어서이고, 요청도 여섯 번에서 한 번으로 줄어듭니다. 번들은
`make_assets.py`가 `.glb`와 함께 만들기 때문에 따로 챙길 일은 없습니다.

꼬리 애니메이션은 뼈마다 위상을 조금씩 늦춘 사인파를 프레임마다 구워 넣은 것입니다. 뼈대는
하나만 두고 재생 속도만 게임에서 바꾸기 때문에, 가속할 때 자연스럽게 빨라집니다.

점액 고리의 구멍은 가운데가 아니라 한쪽에 있습니다. 게임은 고리를 통로 축 기준으로 돌려서
구멍 위치를 매번 다르게 만듭니다. `make_assets.py`의 `RING_HOLE_OFFSET`·`RING_HOLE_RADIUS`와
`js/game3d.js`의 같은 이름 상수는 반드시 같은 값이어야 합니다.

### 에셋 다시 만들기

블렌더가 설치돼 있으면:

```bash
blender --background --python tools/make_assets.py
```

블렌더를 따로 깔지 않고 파이썬 모듈로 돌릴 수도 있습니다. 이 저장소의 에셋은 이 방법으로
만들었습니다.

```bash
python3.13 -m venv ~/blenderenv && ~/blenderenv/bin/pip install bpy
~/blenderenv/bin/python tools/make_assets.py
```

## 파일 구조

```
index.html        # 화면 뼈대, HUD, 시작/결과 카드
styles-3d.css     # HUD와 3D 화면 전용 스타일 (2D판 styles.css 위에 얹음)
js/world.js       # 통로 좌표계, 통로 메시, 장애물 배치
js/game3d.js      # 장면 구성, 에셋 로딩, 게임 루프, 충돌, 화면 전환
tools/make_assets.py  # 블렌더 에셋 생성기
assets/*.glb      # 생성된 3D 모형 (스크립트로 재생성 가능)
vendor/           # three.js와 GLTFLoader 사본 (MIT, vendor/THREE-LICENSE 참고)
```

구간 이름과 생명 상식, 마무리 가족 질문은 2D판 `js/rules.js`를 그대로 읽습니다. 글은 한 군데서만
고치면 양쪽에 반영됩니다.

## 좌표 이야기

3D판의 위치는 세 숫자로 나타냅니다.

- `s`: 출발점에서 통로를 따라 나아간 거리
- `u`, `v`: 통로 중심선과 직각인 단면 위의 위치

장애물은 단면 위 극좌표(각도, 반지름)로 둡니다. 점액 고리의 구멍도 같은 극좌표라서 고리를
각도만큼 돌리면 구멍이 바로 그 자리에 옵니다.

## 2D판과 다른 점

- WebGL이 필요합니다. 아주 오래된 기기에서는 2D판이 더 안전합니다.
- 로컬 서버가 필요합니다(위 참고). 2D판은 파일을 더블클릭해도 실행됩니다.
- 기록은 2D와 따로 셉니다(`sperm-journey-3d-best-v1`).
