## 1. 한 줄 정의

동네 꽃집에서 **버려질 예정인 생화**를, 꽃집에게는 무료 재고관리 도구로 잡아내고,
소비자에게는 **반경 2km 푸시 알림**으로 즉시 팔아넘기는 하이퍼로컬 마감판매 서비스.

## 2. 사업성 평가 (원문 기준)

| 형태 | 점수 |
| --- | --- |
| 버리는 꽃을 지도에서 찾아 사는 앱 (단독) | 5 / 10 |
| 꽃집 재고관리 + 자동 마감판매 플랫폼 | 7.5 / 10 |
| 위 + 웨딩·기업 행사꽃 회수 서비스 결합 (사회적기업형) | 8 / 10 |

핵심 논지: **지도 앱 단독으로는 약하다.** 재고관리 도구를 무료로 깔아주고 그 재고를
판매하는 구조여야 공급이 안정된다.

## 3. 꽃 상태별 활용 전략

| 꽃의 상태 | 활용 방법 | 사업성 |
| --- | --- | --- |
| 아직 싱싱하지만 남은 꽃 | 동네 픽업 '랜덤 구조꽃 묶음' | 높음 |
| 경매에서 유찰된 못난이꽃 | 전국 택배 구조꽃 박스 | 높음 |
| 결혼식·기업행사에 한 번 사용한 꽃 | 작은 꽃다발로 재제작해 판매·기부 | 중상 |
| 약간 시든 꽃 | 압화·염색·카드·기업 워크숍 재료 | 중간 |
| 완전히 시든 꽃·줄기·잎 | 퇴비업체 연결 | 낮음 |
| 식품·차·입욕제·화장품 | 잔류농약과 인허가 문제 | 비추천 |

식용으로 재배한 꽃이 아닌 일반 절화는 안전사용기준·잔류허용기준이 적용되지 않으므로
**먹는 것·바르는 것으로의 전환은 금지선으로 둔다.**

## 4. MVP 상품 규격 — '동네 랜덤꽃 픽업'

꽃집이 마감 전에 버튼 하나만 누르면 등록되는 단일 SKU:

- 랜덤 생화 5~8송이
- 가격 5,900원 / 8,900원 / 12,900원 중 선택
- "예상 감상기간 3일 이상" 표시
- 2시간 이내 매장 픽업
- 선물용 포장 없음 (크라프트지 1회 또는 고무줄 묶음)
- 꽃 종류 선택 불가
- 반경 2km 이용자에게만 알림

설계 제약 두 가지:

1. **꽃집의 추가 작업시간이 10분을 넘으면 참여하지 않는다.** → 재제작이 아니라
   '가정용 꽃병 꽃' 규격으로 고정.
2. **지도보다 알림이 먼저다.** 꽃은 매일 모든 가게에서 남는 게 아니라서, 지도를 열었는데
   비어 있으면 재방문이 끊긴다. 이용자는 지역·가격·색상을 **미리 등록**하고, 물량이
   생겼을 때만 푸시를 받는다.

빈 상태 UX 문구(원문 지정):

> 지금 구조를 기다리는 꽃이 없어요.
> 반경 2㎞ 안에 꽃이 등록되면 알려드릴게요.

푸시 문구 형태: `오목교역 500m, 구조꽃 3개 등록`

## 5. 공급은 왜 존재하는가

- 도매시장 거래 단위는 보통 한 단(10~20송이)인데, 꽃다발 하나에는 특정 꽃을 2~3송이만
  쓰기도 한다 → **작은 꽃집일수록 잔여 재고가 생긴다.**
- 그러나 운영을 잘하는 곳은 남는 꽃 자체가 거의 없다. 원문은 원모먼트 폐기율 2.3%,
  어니스트플라워 3% 미만(자체 ERP)을 근거로 든다.

이 말은 두 가지를 동시에 뜻한다.

- 폐기 문제는 실제로 존재한다.
- 잘하는 꽃집은 팔 물건을 내주지 않는다.

→ 따라서 **"남는 꽃을 달라"가 아니라 "폐기율을 낮춰주는 도구를 공짜로 주고, 그래도 남는
재고를 우리 채널로 판다"** 가 되어야 한다.

`⚠︎ 검증`: 어니스트플라워 3% 미만·ERP 주장은 매체 기사로 확인됨. **원모먼트 2.3%는
확인되지 않음**(원문 접근 차단, 검색상으로는 "폐기율 2%" 표현만 언급). 대외 자료에
인용하지 말 것. → [validation.md §3](./validation.md)

## 6. 꽃집용 무료 재고관리 도구 (공급 확보 수단)

- 입고한 꽃을 **음성으로 등록** — "장미 1단, 화요일 입고"라고 말하면 자동 기록
- 품종별 **마감판매 추천일** 알림
- 남은 수량을 눌러 **즉시 구조꽃 등록** (마감판매 전환 1탭)
- 월별 **폐기 추정 원가 · 구조 판매액 보고서**
- 어떤 꽃이 어느 요일에 남는지 기반 **발주 추천**

이 도구가 실제 진입장벽이자 락인이다. 판매 채널은 그 위에 얹히는 부산물로 본다.
