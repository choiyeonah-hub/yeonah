먼저ON 시작하기

가족이 기억해야 할 일을,
가족보다 먼저 기억하는 앱

아이 나이, 차, 반려동물 같은 우리 집 사정을 알려주면 챙길 일을 알아서 짜둡니다. 그리고 때가 되면 먼저 알려줍니다.
목록을 직접 만들지 않으셔도 됩니다.

· 베타 기간 완전 무료예요 · 설치할 앱이 없습니다. 웹으로 바로 씁니다 · 알림은 하루 한 번, 아침 8시만 갑니다
5분이면 끝납니다

아이폰에서 시작하기

  1. 사파리로 열기

    카톡에서 링크를 바로 누르면 안 됩니다. 카톡 안에서 열린 창은 알림을 못 켭니다.

    링크를 손가락으로 꾹 눌러 → 복사 → 홈 화면의 사파리 🧭 를 열고 주소창에 붙여넣기

  2. 로그인 전에 홈 화면에 추가

    순서가 중요합니다. 먼저 추가해야 로그인을 한 번만 하고, 알림도 받을 수 있어요.

    화면 아래 가운데 공유 버튼 □↑ → 아래로 내려 “홈 화면에 추가” → 오른쪽 위 추가

    홈 화면에 먼저ON 아이콘이 생깁니다. 앞으로는 이 아이콘으로 들어오세요.

  3. 홈 화면 아이콘으로 들어가서 로그인

    이메일 주소를 넣고 로그인 링크 받기를 누르세요.

  4. 메일의 숫자를 입력

    메일이 오면 링크는 누르지 마세요. 링크를 누르면 그 숫자가 못 쓰게 됩니다.

    메일에 적힌 숫자만 보고, 앱으로 돌아와서 입력하세요.
    메일이 안 보이면 스팸함도 봐주세요.

  5. 알림 켜기

    오른쪽 위 톱니바퀴 ⚙ → 아래로 내려 알림 → 알림 켜기
    아이폰이 물어보면 “허용”을 눌러주세요.

    “지금 이 기기 · 등록됨” 이라고 나오면 성공입니다.
    바로 아래 “지금 테스트 알림 받아보기”로 확인해 보세요.
3분이면 끝납니다

안드로이드에서 시작하기

  1. 크롬으로 열기

    카톡 안에서 열린 창은 알림을 못 켭니다.

    카톡에서 열렸다면 오른쪽 위 ⋮ → “다른 브라우저로 열기” 또는 “Chrome으로 열기”

  2. 로그인

    이메일을 넣고, 메일에 온 링크를 누르거나 숫자를 입력하세요. 둘 다 됩니다.

    메일이 안 보이면 스팸함도 봐주세요.

  3. 알림 켜기

    오른쪽 위 톱니바퀴 ⚙ → 아래로 내려 알림 → 알림 켜기 → 허용

    “지금 이 기기 · 등록됨” 이 나오면 성공입니다.

  4. 홈 화면에 추가 (선택)

    오른쪽 위 ⋮ → “홈 화면에 추가”
    안 하셔도 알림은 옵니다. 매번 주소를 치기 번거로우실 때만요.

먼저ON 열기 아이폰은 위 순서대로 사파리에서 열어주세요

막히면 여기를 보세요

메일이 안 와요
스팸함을 먼저 봐주세요. 그래도 없으면 앱에서 “숫자 다시 받기”를 눌러주세요.
메일이 여러 번 왔다면 가장 마지막에 온 것의 숫자를 쓰셔야 합니다.
숫자를 넣었는데 안 맞대요
메일의 링크를 이미 누르셨을 가능성이 큽니다. 링크를 한 번 누르면 그 숫자는 못 쓰게 됩니다.
“숫자 다시 받기”를 누르고, 새로 온 메일의 숫자를 링크는 건드리지 말고 넣어주세요.
“알림을 켤 수 없다”고 나와요
카톡·네이버 앱 안에서 보고 계신 겁니다. 화면 아래에 카톡이나 네이버 표시가 있는지 봐주세요.
주소를 복사해서 사파리(아이폰) 또는 크롬(안드로이드)으로 다시 열어주세요.
아이폰인데 “홈 화면에 추가” 안내가 계속 떠요
아직 사파리에서 보고 계신 겁니다. 애플이 홈 화면에 추가한 앱에만 알림을 허용합니다.
공유 버튼 □↑ → 홈 화면에 추가 → 생긴 먼저ON 아이콘으로 다시 들어와 주세요.
알림을 켰는데 안 와요
앱에서 “지금 테스트 알림 받아보기”를 누른 뒤, 화면을 벗어나(옆면 버튼으로 화면 끄기) 잠금화면을 봐주세요. 앱을 보고 있으면 알림이 안 뜹니다.

그래도 안 오면 집중 모드가 켜져 있는지, 그리고 아이폰 설정 → 알림 목록에서 먼저ON의 “잠금 화면”이 체크돼 있는지 봐주세요. (설정 검색으로는 안 나옵니다. 목록을 내려서 찾으셔야 해요)
가족도 같이 쓰려면요?
가족도 각자 본인 이메일로 로그인해야 합니다. 누가 무엇을 맡았는지 구분해야 하니까요.
먼저 들어오신 분이 화면 위 “가족 초대 링크 복사”를 눌러 보내주시면, 그 링크로 들어온 가족은 같은 집이 됩니다.
제 정보는 어떻게 되나요?
말씀하신 원문과 올리신 사진은 저장하지 않습니다. 사진은 크기를 줄여 AI에 보내고 바로 버립니다.
서비스 개선을 위해 정리된 할 일의 제목만 익명으로 남습니다. 누가 말했는지는 함께 남기지 않습니다. 광고에 쓰거나 밖으로 팔지 않습니다.

앱 안 설정 → 무엇이 남나요에서 다시 보실 수 있습니다.
베타에 함께해 주셔서 고맙습니다.
안 되는 것, 이상한 것, 짜증 났던 것 무엇이든 알려주세요.
