# 결정과 근거

앱을 고치면서 같이 정리한 판단들입니다. 코드보다 오래 남을 내용만 적었습니다.

---

## 1. 베타는 15가구인가 50가구인가

**둘 다 맞습니다. 순서가 다를 뿐입니다.**

지금 필요한 건 “쓸 만한가”이지 “얼마나 쓰는가”가 아닙니다. 이 단계에서 50가구를 받으면
같은 문제를 50번 듣게 되고, 고칠 시간에 응대만 하게 됩니다.

| | 15가구 (2주) | 50가구 (그 다음 4주) |
|---|---|---|
| 알고 싶은 것 | 무엇이 고장났나 · 어디서 막히나 | 계속 쓰나 · 얼마나 자주 열까 |
| 보는 숫자 | 새 일 비율, 막힌 화면, 말로 남긴 불평 | 2주차 잔존율, 주 3회 이상 여는 가구 비율 |
| 필요한 것 | 한 명씩 붙잡고 듣기 | 자동화된 지표 (`beta_metrics` 뷰) |
| 못 하면 | 다음 단계로 못 감 | 발표 자료의 숫자가 안 나옴 |

**추천 순서: 15가구 2주 → 고치기 1주 → 50가구 4주.**
15가구에서 나온 불만을 못 고친 채 50가구로 가면, 50명분의 같은 불만이 쌓입니다.

한 가지 조건이 있습니다. 15가구는 **모르는 사람이 최소 5가구**여야 합니다.
아는 사람은 안 쓰면서도 좋다고 말해줍니다. 그 5가구가 진짜 답을 줍니다.

## 2. 개인정보 — 짚어봐야 할 것

말씀하신 기능 중 법적으로 무게가 다른 것들이 섞여 있습니다.

### 민감정보에 해당하는 것 (개인정보보호법 제23조)

**건강 정보는 별도의 명시적 동의가 필요합니다.** 일반 동의에 묻어갈 수 없습니다.

- **부인 몸 컨디션** — 좋아요/보통/힘들어요는 건강 상태 기록입니다. 게다가 부부 공유라
  “당신 어제 힘들다고 했잖아”가 가능해집니다. 걱정하신 게 맞습니다.
  → **설정에 “가족에게 보이기” 스위치를 넣었습니다.** 끄면 나만 봅니다.
  → 정식 서비스로 가면 이 항목은 **가입 시 동의를 따로 받고, 기록은 당일치만 남기고 지우는 게** 안전합니다. 지금은 날짜 하나만 저장하고 이력을 쌓지 않습니다.
  → “계속 아프다고 하면 어떡하나” — 앱이 판단할 문제가 아닙니다. 3일 연속 ‘힘들어요’면
     목록을 줄이는 것까지가 앱의 몫이고, 그 이상은 하지 않는 게 맞습니다.
- **예방접종·병원·약 기록** — 아이와 부모님 것 모두 건강정보입니다.
  지금은 “예방접종 확인하기” 같은 **할 일 제목만** 저장하고 접종 이력 자체는 저장하지 않습니다.
  이 선을 넘지 마세요. 넘는 순간 의료정보 취급 기준이 따라옵니다.

### 만 14세 미만 아동 정보 (제22조의2)

- 아이 이름·나이·유치원 정보는 **법정대리인 동의**가 필요합니다.
  부모가 직접 넣는 구조라 실질적으로는 충족되지만, 개인정보처리방침에 그 근거를 적어두세요.
- **아이 이름은 별명으로 충분합니다.** “첫째”가 기본값인 건 그래서입니다. 실명을 권하지 마세요.

### 알림장 사진 스캔 — 가장 조심할 부분

알림장에는 **우리 아이 정보만 있는 게 아닙니다.** 다른 아이 이름, 담임 선생님 이름,
전화번호, 반 전체 공지가 같이 찍힙니다. 이건 **제3자의 개인정보**입니다.

지금 구현에 넣은 안전장치:
- 사진을 1200px로 줄여 **EXIF(위치·기기 정보)를 떼고** 보냅니다.
- 사진은 **앱에 저장하지 않습니다.** AI에 한 번 보내고 버리고, 뽑아낸 할 일만 남습니다.
- 프롬프트에 **“개인 이름은 옮기지 마세요”**를 넣었습니다.
- 서버 로그에 사진과 프롬프트를 남기지 않습니다.

그래도 남는 위험이 있습니다. Anthropic API로 전송은 됩니다.
→ 개인정보처리방침에 **“AI 처리를 위해 국외(미국)로 이전됨”**을 반드시 적어야 합니다 (제28조의8).
→ 베타 안내문에 한 줄 더: “사진에 다른 아이 이름이 보이면 가리고 찍어주세요.”

### 안전한 편인 것

- 집안일 목록, 주기, 담당자, 장바구니 — 민감하지 않습니다.
- 자동차 주행거리·연비 — 개인정보이긴 하나 민감정보는 아닙니다.
- 관리비 납부일 — 단지를 특정할 수 있지만 날짜만으론 무리입니다.

### 지금 당장 해야 할 것

1. **개인정보처리방침 페이지**를 만드세요. 베타라도 필요합니다. 최소 항목:
   수집 항목 / 이용 목적 / 보관 기간 / **국외 이전(Anthropic, 미국)** / 파기 방법 / 문의처.
2. 베타 참가 동의서에 **컨디션·아이 정보·사진 스캔**을 따로 체크하게 하세요.
3. 베타가 끝나면 **참가자 데이터를 지운다는 약속과 실제 삭제**를 하세요.
   설정의 ‘데이터 전체 삭제’가 그 창구입니다.

## 3. 제휴는 어떤 식으로 붙는가

### 지금 붙어 있는 것

`index.html`의 `LINKS` 배열 한 곳에 모아뒀습니다. 태그가 세 종류입니다.

- **정보** — 공공기관. 예방접종도우미, 아이사랑, 정부24, 아이돌봄서비스, 가족센터,
  학교알리미, 오피넷, 자동차민원포털. **대가가 없어서 표기 의무도 없습니다.**
- **추천** — 민간 서비스인데 돈을 안 받는 상태. 쿠팡, 만개의레시피, 유튜브 검색,
  아자스쿨, 놀이의발견, 키즈노트, 이사 견적.
- **광고** — **대가를 받으면 반드시 이걸로 바꿔야 합니다.** 표시광고법 위반은 과징금 대상이고,
  “제휴”라고만 써도 부족합니다. 쿠팡 파트너스를 붙이는 순간 이 태그로 바꾸세요.

한 자리에 **최대 2개**만 뜹니다. 광고판처럼 보이면 앱을 안 씁니다.

### 물어보신 것들에 대한 답

- **아이돌봄센터·문화센터 연결** — 지역마다 운영 주체가 달라서 전국 API가 없습니다.
  정부 아이돌봄서비스와 가족센터(전국 단위)로 보내는 게 현실적입니다.
  “우리 동네”는 지도 검색으로 넘기는 게 낫습니다. 직접 DB를 만들면 관리가 안 됩니다.
- **키즈노트 제휴로 준비물 자동** — 제휴가 되면 가장 좋습니다. 다만 알림장 데이터는
  어린이집이 주체라 **회사 간 계약만으로 안 되고 원의 동의가 필요할 가능성**이 높습니다.
  그래서 **사진 스캔을 먼저 넣었습니다.** 제휴 없이 오늘 되는 방법이고, 제휴가 되면 그때 바꾸면 됩니다.
- **유튜버 제휴** — 개인 유튜버와 계약하면 그 사람이 채널을 접었을 때 링크가 죽습니다.
  지금은 **검색어를 넘기는 방식**입니다. 제휴를 하시려면 채널 하나가 아니라
  “레시피 카테고리 몇 개”를 다루는 MCN과 하시는 게 낫습니다.
- **꼭 한 개일 필요는 없다** — 동의합니다. 그래서 `LINKS`는 배열이고 조건에 맞는 걸
  최대 2개까지 보여줍니다. 셋 이상은 고르기 싫어집니다.

### 붙일 때 순서

1. 링크 클릭 수를 먼저 보세요 (`설정 → 베타 지표 → 제휴 링크 클릭`).
2. 클릭이 실제로 나오는 자리에만 제휴를 제안하세요. 클릭 0인 자리는 협상 카드가 없습니다.
3. 계약이 되면 `LINKS`의 해당 항목에서 `tag`를 `"광고"`로 바꾸고 URL에 제휴 코드를 넣으세요.

## 4. 알림 — “장바구니 넣어놓고 깜박”은 어떻게 푸나

깜박하는 문제는 알림으로 다 못 풉니다. 알림이 오면 그때 못 사고, 살 수 있을 때는 알림이 없어서요.
그래서 세 가지를 같이 넣었습니다.

1. **오래 담긴 것을 스스로 올림** — 장바구니에 7일 넘게 있으면 “담아두고 잊으신 것”으로 올라오고,
   버튼 하나로 이번 주 할 일이 되거나 바로 주문으로 이어집니다.
2. **살 것이 생기면 그 자리에서 장바구니로** — 말하기 결과의 ‘구매’ 묶음과 개별 할 일에
   🛒 버튼을 붙였습니다. 나중에 다시 적을 일이 없습니다.
3. **오늘 화면에 남은 개수** — 앱을 열면 항상 보입니다.

닫힌 앱을 깨우는 진짜 푸시는 서비스워커 + Web Push + 서버 스케줄러가 필요합니다.
15가구 베타에서는 굳이 필요 없고, 50가구로 갈 때 넣는 게 순서에 맞습니다.
그때 보낼 알림은 딱 셋으로 좁히세요: **넘어온 일 / 오늘 안 하면 늦는 일 / 휴일 브리핑.**
그 외에 보내면 알림을 통째로 끕니다.
