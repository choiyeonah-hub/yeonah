# 말이음 — 클릭형 시제품

북한이탈여성이 병원·취업·어린이집·은행·주거 현장에서 쓰는 남한 생활언어를 상황극으로 익히는
모바일 학습 서비스의 **클릭형 프로토타입**입니다. 하나센터에 공동 수요조사를 제안할 때
1페이지 사업개요와 함께 보여주기 위한 화면 모형이며, 작동하는 앱이 아닙니다.

- 파일: `index.html` 한 장. 빌드·설치 없이 브라우저에서 바로 열면 됩니다.
- 화면 8장: 홈 → 병원 장면 → 음성 역할극 → 표현 카드 → 어린이집 알림장 → 직장 단톡방 → 퀴즈 → 수행 전후 기록
- 화면 안의 버튼, 왼쪽 목록, 좌우 방향키, 휴대폰에서는 좌우 스와이프로 이동합니다.
- 아래쪽에 1페이지 사업개요, 하나센터 협조 요청문, 인터뷰 문항 초안이 함께 들어 있습니다.

## 만들 때 지킨 것

- **화면 어디에도 “탈북·북한이탈주민” 표시를 두지 않았습니다.** 휴대폰 화면에 대상자 신분이
  드러나는 것을 꺼릴 수 있어, 이름과 아이콘을 일반 생활학습 앱처럼 두었습니다.
- **북한식 대응 표현 칸은 비워 두었습니다.** 북한 교사 출신 감수자가 확인한 것만 채웁니다.
  확인된 대응어(어린이집↔탁아소, 도시락↔곽밥)만 화면에 넣었습니다.
- **“국내 최초”라는 표현을 쓰지 않았습니다.** 통계 수치도 확인 전 값을 넣지 않았습니다.
  누적 입국 북한이탈주민의 여성 비율은 통일부 공식 통계로 확인한 뒤 인용 시점과 함께 적으세요.
